# Accounts, JWT and groups

Replace Nginx Basic Authentication with public registration/login pages and authenticated APIs. Username is case-insensitive, 3-32 ASCII letters/digits/underscores/hyphens; passwords are 8-256 characters and stored as salted PBKDF2-SHA256 hashes with 600000 iterations. Use PyJWT with a fixed HS256 algorithm, validated issuer/audience/subject/session claims and expiry exactly 86400 seconds after issue. Carry only the access JWT in an HttpOnly SameSite=Lax cookie (Secure on HTTPS); no refresh token. Persist signing key and revocable session metadata. Logout revokes the session and clears the cookie. Reject cross-origin writes, limit authentication attempts, and ignore client-provided identity headers.

Every diagram has an immutable creator user ID and optional group ID. Personal diagrams are visible only to their creator. Members can view/edit active diagrams shared with their group; only the creator can reassign or deactivate a diagram. Membership checks happen on every API operation. Group owners can rename groups, add registered users by username and remove members; members can leave. Owners cannot remove themselves. No user directory endpoint exposes all accounts.

Migrate the current owner field to creator IDs transactionally while retaining legacy ownership, source, active flags and delete-blocking triggers. Seed meow from an external password hash file, using the existing password, before allowing registration. Other legacy owners receive locked placeholders instead of exposing or transferring their diagrams. Add foreign keys plus creator immutability/required-creator triggers. SQLite data, signing keys and bootstrap hashes stay excluded from Git and images.

Frontend provides login/register, username/sign-out controls, a personal/group library filter, diagram group assignment and a group-management dialog. Drafts/preferences/migration keys are scoped by user ID; legacy browser drafts import only for meow. Sign-out/expiry unmounts the workspace and preserves only that user's pending drafts. Authentication expiry returns the login screen. Existing editing, templates, themes, exports and diagram retention remain integrated.
