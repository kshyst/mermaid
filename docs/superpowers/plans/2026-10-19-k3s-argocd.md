# Mermaid K3s Implementation Plan

> **For agentic workers:** Execute inline with executing-plans, following the approved design.

**Goal:** Release Mermaid from main through GHCR and Argo CD without server SSH deployment.

**Architecture:** CI validates and publishes two images. A rendered, immutable
release on `deploy/production` drives Argo CD. SQLite remains single-writer
on persistent local-path storage.

**Tech Stack:** GitHub Actions, Docker, Kustomize, K3s, Argo CD, Traefik, cert-manager.

## Global Constraints

- Source branch `main`; deployment branch `deploy/production`.
- Hostname `mermaid.kshyst.ir`; node `control-1`; namespace `mermaid`.
- Existing server and data remain untouched by local work.
- No secrets or generated data enter Git.
- API replica count is one and deployment strategy is Recreate.

Files: `deploy/kubernetes/*`, `deploy/render-release.sh`,
`deploy/argocd/*`.

- [x] Create frontend/API Deployments and Services, persistent storage,

## Task 2: Automated image publication and GitOps snapshot

- [x] Run `npm ci`, `npm test`, `npm run build`, then Python requirements

- [x] Build/push both existing Dockerfiles after successful tests.
- [x] Render using the build action's immutable digest outputs.

  creating an orphan branch on the first build, checking main freshness and
  pushing without force. Save source revision and image digests as JSON.
- [x] Validate action expressions, permissions and workflow syntax.
